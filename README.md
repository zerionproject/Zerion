# Zerion
Zerion is a secure, anonymous messaging app designed for privacy-conscious users who need a safe, easy and robust way to communicate without compromising their identity or data.

Built on advanced peer-to-peer technology, Zerion doesn't rely on central servers - messages are synchronized directly between users' devices, ensuring complete privacy and metadata protection.

## Key Features

### 🔐 **Ultimate Privacy**
- **No phone number or email required** - stay completely anonymous
- **End-to-end encryption** - messages can only be read by you and your contacts
- **Metadata resistant** - no central server to track who talks to whom
- **No data collection** - your information stays on your device

### 💬 **Modern Messaging Experience**
- **Swipe to reply** - quickly respond to specific messages
- **Long-press menu** - easy access to reply, copy, and delete options
- **Private groups** - create secure group chats for sensitive discussions
- **Auto-delete timers** - messages can disappear after being read

### 🌐 **Resilient Communication**
- **Works without internet** - sync via Bluetooth or Wi-Fi when offline
- **Tor integration** - route messages through Tor for maximum anonymity
- **Crisis-proof** - keeps working even when infrastructure fails
- **Decentralized** - no single point of failure or control

## Building from Source

### Requirements
- Android Studio (latest version)
- Java 11 or Java 17
- Android SDK with build tools
- Git

### Build Instructions
```bash
# Clone the repository
git clone git@github.com:ProfessorYega/zerion.git
cd zerion

# Build debug APK
./gradlew.bat assembleDebug

# Build release APK
./gradlew.bat assembleRelease
```

The compiled APK will be in `briar-android/build/outputs/apk/`

## Privacy Policy

Zerion collects **no personal data**. We don't have servers to store your data on. All information stays on your device and is only shared with your explicit contacts through encrypted peer-to-peer connections.

Key privacy features:
- No account registration required
- No phone number or email needed
- No analytics or tracking
- No cloud backups
- No metadata collection
- Your contacts and messages stay on your device
