# Zerion security claims: what is enforced, where, and since when

Every public security claim the project makes, with the code that enforces it, the test that proves it, its threat-model limits, the first version that shipped it, its current status and its external review status. Website and README wording is derived from this file; a claim that is not in this file is not made. The finer-grained protocol invariants are in [SECURITY_CLAIMS_MATRIX.md](SECURITY_CLAIMS_MATRIX.md).

Status values: **CODE-ENFORCED** (a named production invariant and a test that ran), **DESIGN GOAL** (implemented as described, no test pins it), Where a row names a release, the status holds from that release on and the limits column records what the earlier release did. External review values: NONE, FOCUSED (an independent focused review covered it), PENDING.

Which host each network feature reaches, and whether the route is onion only, clearnet through a Tor exit or direct, is listed in [NETWORK_PATHS.md](../NETWORK_PATHS.md).
