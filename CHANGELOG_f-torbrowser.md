# Changelog entries for the Tor Browser link feature (3.0.19)

- Links: when Tor Browser is installed, a link from a chat, channel, group or the donation screen, the release page in the update dialog and the wallet's "View on mempool (Tor)" button open in Tor Browser, after a confirmation that says the connection stays inside Tor; the system browser is not offered then. Without Tor Browser the warning that a link leaves Tor is unchanged and gains a "Get Tor Browser" button: it opens Google Play when Zerion was installed from Play, adds the Guardian Project repository to the F-Droid client when Zerion came from an F-Droid client, and otherwise opens the Tor Project download page after the usual warning. The update dialog's Open button now asks before it opens the release page, as other links do; before, it opened the system browser at once. The wallet's explorer button no longer hands the onion address to the system browser: without Tor Browser it copies the transaction ID and offers Get Tor Browser.
