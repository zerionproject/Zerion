v3.0.0: offline mesh, I2P, and hardening

Zerion 3.0 adds offline messaging. When there is no internet, nearby devices connect directly over Bluetooth so you can send messages, replies, and photos, in both one to one and group chats. Online messaging continues to run over Tor, now with bridge support (obfs4, snowflake, meek) for harder to block connections, plus an optional embedded I2P transport.

This release also strengthens the app: per message post-quantum encryption throughout, a hardened mode with tamper detection enabled by default, an app signature self check, and reproducible builds. Both people need this version to message each other.

Note added September 2026: in current releases hardened mode is off by default (three opt-in protections), I2P is no longer in the published app, and reproducible builds were not yet achieved: the first byte-identical reproduction of a release is recorded for 3.0.12.
