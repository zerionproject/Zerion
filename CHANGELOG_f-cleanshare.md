Changelog bullets for the 3.0.19 section (to be merged into CHANGELOG.md by the release owner):

- Clean a file: the main screen's menu has a new entry, "Clean a file". Pick any file on the phone and Zerion removes its hidden information with the same cleaners it uses for chats and the vault: a photo is decoded and re-encoded, a video or sound file is remuxed, a PDF is redrawn page by page (it keeps its look but loses its text layer, links and forms), a Word, Excel or PowerPoint file loses its document properties (comments, tracked changes and pictures inside it are kept), and plain text is checked. The screen shows the type and size before and after and says in plain words what was done; the clean copy can then be shared to any app or saved. The original file is never changed, a file that cannot be cleaned is refused with a message instead of being passed on unchanged, and files over 128 MB are refused. Zerion does not appear as a share target in other apps; the tool is reached from Zerion only. A shared copy lives in the app's cache for the other app to read; it is erased when the app locks, when you sign out, when the service starts, at the next start of the app, and when the Clean a file screen is closed more than ten minutes after the share.
